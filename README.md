# サンタさんのプレゼント大作戦

[ゲームであそぶ](https://test553378.github.io/Christmas-Games/) · [ソースリポジトリ](https://github.com/test553378/Christmas-Games)

4〜6歳の子どもが、iPadのSafariでタップして遊ぶクリスマスの2Dゲームです。
部屋・キャラクター・装飾はオリジナルのCanvas描画、効果音はWeb Audioの合成音です。
画像ダウンロード、APIキー、アカウント登録、外部ライブラリは不要です。

## あそびかた

1. 「あそぶ」を押します。
2. ベッドをタップすると、サンタさんがその子の前まで歩きます。床もタップできます。
3. 近くで「すずをならす」を3回押します。1回ごとに0.8秒待ちます。
4. 起きた子の近くで、緑になった「プレゼントをわたす」を押します。
5. ステージ1は女の子1人、ステージ2は女の子と男の子2人に届けます。

制限時間はステージ1が30秒、ステージ2が45秒です。**全員が起きると、その瞬間に時計が止まります。**
そのあとプレゼントを渡す時間に制限はありません。失敗したら同じステージから再挑戦できます。

パソコンでもマウスで操作できます。キーボードは、左右矢印で移動、スペースまたはBで鈴、Gでプレゼント、Escで一時停止です。
「あそびかた」や「おやすみ」を開いている間、別タブに移った間は、時計・移動・受け渡しが止まります。

## ローカル起動

ZIPを展開して、`index.html`のあるディレクトリで実行します。

```sh
python3 -m http.server 8000
```

ブラウザで `http://localhost:8000` を開いてください。
WindowsでPythonランチャーを使う場合は `py -m http.server 8000` でも起動できます。
ES Modulesを使っているため、HTMLファイルを直接ダブルクリックする`file://`形式では起動しません。
ビルドや`npm install`は必要ありません。

同じWi-FiのiPadで確認する場合は、PCのローカルIPアドレスを使って `http://PCのIP:8000` を開きます。
必要に応じてPCのファイアウォールでポート8000のローカル接続を許可してください。

## テスト・静的ファイル生成

Node.js 20以降を使用してください。追加の依存ライブラリはありません。

```sh
npm test
npm run build
```

`npm test`はNode.js標準テストランナーを使います。`npm run build`は配信用ファイルだけを`dist/`にコピーします。
`dist/`もそのままHTTPサーバーから配信できます。

ゲーム内部は960×540、移動速度240px/秒、移動範囲60〜900、床基準Y=405です。

同距離の贈り物対象は女の子が優先です。数値は`src/config.mjs`にまとめています。

## GitHub Pagesへの公開

### GitHub Actionsを使う方法

1. 自分のGitHubにリポジトリを作成します。
2. このフォルダーの**中身**をリポジトリのルートに配置し、`main`へpushします。隠しフォルダー`.github`も含めてください。
3. リポジトリの **Settings → Pages → Build and deployment → Source** で **GitHub Actions** を選びます。
4. **Actions → Publish game to GitHub Pages → Run workflow** を実行します。設定後は`main`へのpushでも更新されます。
5. 成功後、PagesのURLを開きます。通常は `https://ユーザー名.github.io/リポジトリ名/` です。

ワークフローはテストを実行し、生成した`dist/`を配信します。通常の公開リポジトリなら有料サービスや追加のAPIキーは不要です。
GitHubの組織ポリシーやプランによるPages/Actionsの利用可否は、ご利用のアカウント設定をご確認ください。

### ビルドなしで公開する方法

`index.html`・`styles.css`・`favicon.svg`・`src/`・`.nojekyll`をリポジトリ直下へ置き、
**Settings → Pages → Deploy from a branch → main / (root)** を選んでも動作します。
すべての参照は相対パスなので、リポジトリ名の付いたサブディレクトリでも利用できます。
どちらか一方の公開方法を選んでください。
